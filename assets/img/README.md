# Изображения сайта КФУ — карта файлов

Положи сюда свои экспорты из Figma **ровно с этими именами**. Пока файла нет — на его месте
показывается художественный плейсхолдер (градиент + иконка), сайт не ломается.

Форматы: `.jpg` для фото/живописи, можно `.webp` (тогда поправь расширение в `index.html`).
Рекомендуемая ширина ≈ 1600–2000 px для широких баннеров, 800–1000 px для карточек.

## Быстро проверить сайт
Просто открой `index.html` двойным кликом — или из этой папки проекта запусти:

```bash
python -m http.server 5500
```

и открой http://localhost:5500
